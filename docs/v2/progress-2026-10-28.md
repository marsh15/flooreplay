# V2 progress — 2026-10-28

> Historical. Written before the decision routes, persistence and the frontend rewiring landed. The current state is in [RELEASE_STATUS.md](../../RELEASE_STATUS.md).

V2 is not an integrated release. The decision screens call provisional endpoints that
are not implemented, and the existing demo and release evidence concern v1. The
unreviewed synthetic note corpus does not establish model accuracy.

This increment adds pure replay and recommendation, case expectations and case
comparison. Replay identifies the snapshot, policy, engine and computed output in a
stable digest. Non-ready gates, unreviewed inputs and unevaluated constraints require
review; approval failures retain the candidate outcome. Overtime can become a
condition. Material shortfalls currently require review: split-shipment feasibility
and remainder dates are not implemented. These functions are not connected to HTTP
or persisted evaluations. They must not be represented as a complete decision flow.

Case comparison reports missing or failed evaluations and differing suite digests as
not comparable. It does not store runs or authorize adoption. The order list now
explains a missing endpoint and points to the v1 investigations.

Remaining critical path: finish recommendation rules and frozen synthetic cases;
persist evaluations and human decisions; implement workspace-scoped APIs, CSV
publishing, review and policy adoption; integrate generated contracts and seed data;
then run live end-to-end and release checks. Human practitioner review, Tamil gold
review and hosted acceptance remain separate outstanding work. No factory benefit or
operational accuracy is established.

Local verification: targeted replay and comparison tests passed (10 tests); targeted
Ruff and backend mypy passed. Docker was unavailable during this work, so database,
migration and clean Compose checks were not run. Frontend lint and build passed; the
missing-endpoint browser test passed with a mocked 404. Older results in the handoff
are historical.
